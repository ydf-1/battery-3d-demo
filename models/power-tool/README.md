# 电动工具电池包 · 离线交互演示

双击 `dist/index.html` 即可运行，无需安装、联网或启动服务器。建议使用支持 WebGL 的现代桌面或手机浏览器。

## 使用

- 拖动旋转，滚轮缩放；手机单指旋转、双指缩放或平移。
- 「完整拆解」「组装」与滑块控制整体拆解程度。
- 点击①，上下壳一起拆出；点击②，上下电芯支架拆出；点击④，端子护罩拆出。
- 点击③，卡扣单独拆出，滑轨固定在上壳上并一起高亮。再次点击同一编号即可归位。
- 其他部件只显示名称；侧面板只使用提供的部件名称与「邦泰推荐」原文。
- 支持自动旋转、标注开关、正视图、等轴视角和键盘操作，详见页面操作指南。

模型为代码生成的行业常见结构示意。电芯按 18650 比例横放，两层、每层五颗，总计十颗；页面不展示整包电压、容量。示意图，仅供参考。

## 源码分工

- `dist/model.js`：几何、材质、部件归属和拆解方向；滑轨是上壳的实际子对象。
- `dist/data.js`：四类编号塑料部件及推荐原文、其他部件名称。
- `dist/app.js`：旋转缩放、拾取、联动、动画、标签与高亮。
- `dist/style.css`：桌面和手机布局。
- `dist/index.template.html`：页面结构。
- `dist/index.html`：已打包的单文件离线成品。
- `build.mjs`、`offline-check.mjs`：打包及离线依赖检查。
- `THREE-LICENSE.txt`：Three.js 许可证；同时保留在成品 HTML 中。

## 重新打包

成品运行不需要 Node.js。仅修改源码并重新构建时，需要 Node.js 22 或以上，在源码目录执行：

```sh
npm install
npm run build
```

安装开发依赖需要联网。生成的 HTML 内联 Three.js、OrbitControls、后处理、脚本、样式与图标，运行时不请求网络，也不使用外部模型、字体或图片。CSP 中 `connect-src 'none'` 禁止网络连接。
