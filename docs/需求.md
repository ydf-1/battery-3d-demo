# 3D电池模型项目需求

本文件依据本项目对话中用户已确认的要求整理。用户已确认直接以本对话内容为准，替代原先提到但未提供的「新对话_3D电池模型.md」。以后每次开工，先读本文件，再拉取仓库最新代码。

## 项目与交付

- 模型范围：两轮车电池包、滑轨式电动工具电池包、落地式户用储能电池柜。三套模型统一纳入本轮成品整合。
- 使用 Three.js、HTML、CSS、JavaScript。所有几何由代码生成，不依赖外部3D模型文件。
- 成品是可双击运行的离线单文件HTML，Three.js和所有运行资源内联，不发出任何网络请求。
- 保持源码分工：`model.js` 管几何，`data.js` 管部件信息，`app.js` 管交互。
- 外形参照行业常见款与本对话附件P2、P4、P3。模型上不放品牌、商标、型号或文字。
- 深色科技背景；塑料外壳哑光黑，其他塑料件亮蓝半哑光，金属保留本色，电路板深绿，电芯银灰。电动工具一体滑轨与上壳同为黑色。
- 只有塑料部件编号①到④，名称及「邦泰推荐」严格照下表原文。
- 点击编号部件可拆出并发光高亮，信息面板只显示编号、名称和对应推荐原文。
- 金属件、电芯、电路板、弹簧和电量灯不编号；点击只显示名称，保持本色，不触发独立拆解。
- 保留整体拆解/组装动画、拆解程度滑块、自由旋转缩放、自动旋转、标注、单件再点归位、桌面和手机布局、操作指南。
- 3D区域下方固定显示「示意图，仅供参考」。
- 不自行增加部件表以外的性能、认证或参数。仅保留下述用户明确允许的整包示意配置。
- 完工说明列出修改、新增的部件和文件。

## 两轮车电池包：P2结构

| 编号 | 名称（原文） | 邦泰推荐（原文） |
| --- | --- | --- |
| ① | 上盖、底座、塑料外壳 | BT-CS 阻燃系列（PC/ABS），户外件加耐候 |
| ② | 电芯支架、铝壳内绝缘支架 | BT-PC 阻燃、增强系列 |
| ③ | BMS支架 | BT-PA66 阻燃增强系列 |
| ④ | 放电口、换电连接器座 | BT-PA66 阻燃增强系列 |

- 提手上盖归①；增加/保留底座，同属①，点击①时上盖与底座一起拆出。
- 绝缘支架归②，电芯组上、下各一块。
- 增加/保留托住BMS电路板的塑料支架，归③；BMS电路板本身不编号。
- 放电口归④，位于底座上，是蓝色塑料插座，内部是金属插片。插座随底座移动，也可独立拆出；金属插片保持独立拾取身份和本色。
- 外壳按铝型材方筒画，金属本色，不编号。汇流排、电芯组、BMS电路板不编号。
- 电芯按21700比例画，直径21mm、长70mm，共65颗，13S5P。
- 整包仅可显示13S5P、48.1V、25Ah，并标「示意配置」。删除其他未经给定的参数。

## 电动工具电池包：P4结构

行业常见的滑轨式电动工具电池包。从上到下：

1. 上壳：顶面两条滑轨与端子插口，和上壳一体；前端按压式卡扣按钮，带金属弹簧；侧面有电量灯。
2. 端子护罩：亮蓝塑料，内部是铜色金属端子。
3. 保护板：深绿色电路板。
4. 电芯：18650圆柱电芯横放，上下两层，每层5颗，共10颗；长度一致，正面能看到两排、每排5个端面；上下两层支架卡住电芯，镍片连接。
5. 下壳：哑光黑。完整拆解时各主层间距均匀，电芯模块不能插入下壳。

| 编号 | 名称（原文） | 邦泰推荐（原文） |
| --- | --- | --- |
| ① | 上下壳 | BT-CS 阻燃系列（PC/ABS）、BT-ABS 阻燃系列、BT-PC 阻燃系列（镭雕级） |
| ② | 电芯支架 | BT-PC 阻燃、增强系列 |
| ③ | 卡扣和滑轨 | BT-CS 系列（PC/ABS），滑轨跟上壳一体，同①选料 |
| ④ | 端子护罩 | BT-PA66 阻燃增强系列 |

- 点击①：上壳、下壳一起拆出。
- 点击②：上下两层电芯支架拆出。
- 点击③：卡扣按钮单独拆出；滑轨与上壳是同一运动组件，不单独拆，和按钮一起高亮。滑轨也响应①的上壳高亮。
- 点击④：端子护罩拆出；内部金属端子保持本色。
- 电芯、镍片、端子、保护板、弹簧、电量灯不编号。不写整包电压、容量参数。

## 户用储能电池柜：P3结构（2026-10-27新增）

沿用现有 Three.js 页面框架，新模型放在 `models/home-storage/`，原有两轮车模型保持原样。

- 落地式白色钣金机柜，前门板可拆开放到一边；顶部是黑色玻璃显示屏，后方为塑料支架和边框。
- 上层是 BMS 电路板及其下方的蓝色塑料绝缘支架。
- 下方两层为银灰色方形电芯模组；电芯之间、底部定位和顶部设置蓝色绝缘件，铜色汇流排上方设置蓝色塑料护罩。
- 柜体侧面有两个穿墙直流连接器，绝缘壳体为橙色，金属端子有独立拾取身份。
- 机柜、门板、显示屏、电芯、汇流排、BMS 电路板不编号；点击只显示名称，保持原色，不触发独立拆出。
- 不写整包电压、容量、串并联、性能或认证参数。图中的单体数量和尺寸比例仅用于结构示意，不定义电气配置。
- 整体拆解先移开门板、显示屏与机柜外壳，露出内部，再展开内部部件；组装反向执行。保留内框与底座，橙色连接器随外壳移动。
- ①显示支架和边框联动；②两层模组的定位件、隔板及护罩联动；③BMS绝缘支架独立展开；④两个橙色连接器壳体联动展开，端子不随局部拆壳移动。再次点击同一编号归位。
- 在组装状态选择内部塑料件时，先打开外部壳件，再展现所选部件。保留整体滑块、旋转、缩放、自动旋转、标注、操作指南、桌面与手机布局。

| 编号 | 名称（原文） | 邦泰推荐（原文） |
| --- | --- | --- |
| ① | 显示面板支架、塑料边框 | BT-CS 阻燃系列（PC/ABS）、BT-PC 阻燃系列 |
| ② | 电芯绝缘定位件、汇流排护罩 | BT-PA66 阻燃增强系列 |
| ③ | BMS绝缘支架 | BT-PA66 阻燃增强系列 |
| ④ | 穿墙连接器绝缘壳体 | BT-PA66 阻燃增强系列，可按需求配色 |
