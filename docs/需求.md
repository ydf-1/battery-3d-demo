### 验收原则

- 每一条要求都要提供截图或数字作为证据；没有证据的一律算没做。
- 做不到或尚未做的，写「没做」和原因，不得写「已完成」。
- 部件名称、编号和「邦泰推荐」原文一字不改；已有版本标签不修改、不移动、不覆盖。
- 当前默认外观改为浅色影棚，保留深色切换按钮，替代原「深色科技背景」默认规则。

### 一、浅色影棚外观

1. 背景使用 CSS 径向渐变，中心 `#FFFFFF`、边缘 `#E6E9EE`；3D画布透明。
2. 使用 `three/addons` 中的 `RoomEnvironment`，经 `PMREMGenerator` 生成环境贴图；色调映射为 `ACESFilmicToneMapping`，曝光 `1.0`，输出色彩空间 `sRGB`，开启抗锯齿。
3. 地面使用 `ShadowMaterial` 呈现软阴影，在模型底下另加接触阴影。
4. 正常状态下所有产品部件材质均不透明（`opacity = 1`、`transparent = false`），按下表统一：

| 材质 | 颜色 | 金属度 | 粗糙度 |
| --- | --- | --- | --- |
| 黑色塑料 | `#1B1D20` | 未指定 | `0.55` |
| 蓝色塑料 | `#1E7BE0` | 未指定 | `0.35` |
| 铝型材 | `#C9CED4` | `1` | `0.3` |
| 电芯 | `#B9BEC4` | `0.9` | `0.25` |
| 铜 | `#C27A3E` | 未指定 | 未指定 |
| 电路板 | `#0E5C3A` | 未指定 | 未指定 |
| 橙色 | `#F07A1A` | 未指定 | 未指定 |
| 白色钣金 | `#EEF0F2` | 未指定 | 未指定 |

铝型材必须呈现不透明金属，不能表现为磨砂玻璃。橙色与白色为本轮统一调色板定义，不据此修改电动工具或储能柜。用户明确要求的选中态灰色20%不透明度是产品材质的临时例外；地面 `ShadowMaterial` 与接触阴影不属于产品部件，可使用透明材质。

### 二、以模型为主的版面

1. 在 `1366×768` 窗口下，3D区域宽度至少占屏幕宽度的 `65%`；组装状态模型高度占3D区域高度的 `75%～85%`。
2. 顶栏高度不超过 `56px`。标题、示意配置与部件清单全部位于右侧栏，侧栏宽 `340px`。
3. 拆解、组装、拆解滑块、自动旋转、重置视角集中为3D区域底部居中的一条悬浮控制条，高度不超过 `56px`。
4. 「示意图，仅供参考」放在3D区域左下角，使用 `13px` 灰字，替代旧版放在3D区域下方的规则。
5. `1366×768` 和 `1920×1080` 两种窗口均不能出现水平或垂直滚动条。

### 三、编号标注与选择交互

1. 拆解状态下①至④四个标注一直显示，数字圆圈直径 `32px`、名称字号 `16px`，带引线；统一排在模型右侧一列，彼此不重叠。
2. 选中①至④任一编号：该编号部件保持原色并增加蓝色柔光（`emissive`），在当前全局拆解位置基础上额外向外移出一段；其他所有部件临时变为灰色、`20%` 不透明度；镜头在 `0.8秒` 内平滑对准该部件。
3. 再点同一编号：部件回到当前全局拆解位置，其他部件恢复原样。在 `0%`、`50%`、`100%` 三种拆解程度下均需验证；部件不能消失或被其他部件挡住。
4. 点击金属件、电芯、电路板只显示名称，不触发移动或材质变化。此前普通状态保持本色的规则继续有效；选中塑料件时的其他部件临时灰色效果按本节第2条处理。

### 四、两轮车拆解层次

1. 完整拆解主列从上到下依次为：上盖、BMS电路板、③BMS支架、②上支架、电芯组、②下支架、底座。④插座随底座，汇流排随电芯组一起移动。铝型材外壳整体平移到左侧，不能与中间主列重叠。
2. 主列上下相邻层的空隙相等，且不小于模型总高度的 `5%`。本轮采用更严格口径：分母为完整拆解后的模型总高度；底座层的占用范围包括随动插座，电芯层包括随动汇流排，并同时保留各独立部件包围盒。
3. 整段拆解动画 `1.6秒`，先慢后快再慢；从外到内每层依次晚 `60毫秒` 启动，组装时按相反顺序。启动延迟包含在整段动画时长内。
4. 用代码计算完整拆解时每个部件的包围盒，写入 `docs/两轮车验收.json`；提供相邻层的净空、重叠判断以及外壳与中间列的重叠判断，证明其互不重叠。

## 电动工具电池包：P4结构

行业常见的滑轨式电动工具电池包。从上到下：

1. 上壳：顶面两条滑轨与端子插口，和上壳一体；前端按压式卡扣按钮，带金属弹簧；侧面有电量灯。
2. 端子护罩：亮蓝塑料，内部是铜色金属端子。
3. 保护板：深绿色电路板。
4. 电芯：18650圆柱电芯横放，上下两层，每层5颗，共10颗；长度一致，正面能看到两排、每排5个端面；上下两层支架卡住电芯，镍片连接。
5. 下壳：哑光黑。完整拆解时各主层间距均匀，电芯模块不能插入下壳。

| 编号 | 名称（原文） | 邦泰推荐（原文） |
| --- | --- | --- |
| ① | 上下壳 | BT-CS 阻燃系列（PC/ABS）、BT-ABS 阻燃系列、BT-PC 阻燃系列（镭雕级） |
| ② | 电芯支架 | BT-PC 阻燃、增强系列 |
| ③ | 卡扣和滑轨 | BT-CS 系列（PC/ABS），滑轨跟上壳一体，同①选料 |
| ④ | 端子护罩 | BT-PA66 阻燃增强系列 |

- 点击①：上壳、下壳一起拆出。
- 点击②：上下两层电芯支架拆出。
- 点击③：卡扣按钮单独拆出；滑轨与上壳是同一运动组件，不单独拆，和按钮一起高亮。滑轨也响应①的上壳高亮。
- 点击④：端子护罩拆出；内部金属端子保持本色。
- 电芯、镍片、端子、保护板、弹簧、电量灯不编号。不写整包电压、容量参数。
