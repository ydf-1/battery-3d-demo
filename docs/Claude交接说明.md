# 给Claude的项目交接说明

先读 `docs/需求.md` 和 `AGENTS.md`。仓库 `ydf-1/battery-3d-demo` 保持私有，用户选择通过ZIP交接，不公开仓库。

项目有三套模型：两轮车电池包、滑轨式电动工具电池包、户用储能柜。当前重点是前两套模型的几何外形与辨识度。用户反馈两轮车不如绿色背景旧版接近参考，电动工具电池包也看不出来，需要对照原图改进。

## 入口与源码

- 直接查看：`release/3D电池模型-成品.html`，双击离线打开，在顶部切换三套模型。
- 两轮车：`dist/model.js`、`dist/data.js`、`dist/app.js`。
- 电动工具：`models/power-tool/dist/model.js`、`data.js`、`app.js`。
- 储能柜：`models/home-storage/`。
- 公共材质、取景、灯光、界面：`shared/`；合并入口：`gallery.mjs`。
- 安装并构建：Node.js 22或以上，根目录执行 `npm install`，再 `npm run build`。

## 当前修订

两轮车恢复带提手的高身铝型材方筒和横置电芯阵列，仍保留65颗21700比例电芯；上、下绝缘支架归②，BMS支架归③，底座插座归④。电动工具改为斜肩上壳、一体T形滑轨、前端凹槽卡扣、收腰下壳与底部护脚；仍为两层各5颗横置18650。编号、名称、推荐原文和联动以需求表为准。

## ZIP附带的参考资料

压缩包的 `参考资料/` 包含用户原始P2、P4图片，以及绿色背景旧版的预览、离线HTML和几何源码，供比较轮廓与结构。该目录是此次交接额外附带的资料，不参与构建。

绿色旧版早于后续部件规则：其配色、文字、参数、编号不可直接恢复。可借鉴其高身比例和构图，成品仍须遵守当前需求，模型上不放文字、品牌或商标。原图是结构示意，不能据此声称完成了可制造的工程设计。

## 继续修改时重点核对

- 先看组装外观能否辨认，再检查完整拆解的层次和遮挡，避免只优化界面。
- 两轮车①的上盖和底座一起动；电动工具③只有按钮单独移动，滑轨附着上壳并高亮。
- 金属、电芯、电路板不编号，点击只显示名称、保持本色；不自行添加参数。
- 电动工具正面须看清两排、每排5个端面，各主层拆解后等距，电芯不穿入下壳。
- 运行 `npm run build`，检查离线单文件与手机布局。浏览器验收脚本在 `tests/`，实际结果在 `docs/*验收.json`，截图只放 `docs/screenshots/`。
- 已发布标签不移动，遵守私有仓库协作规则。

ZIP不含 `node_modules`、`.git` 或本机Git登录信息。用户将自行上传此文件给Claude。
