## 构建复验

使用新目录从远程克隆，安装依赖后构建：

```powershell
git clone https://github.com/ydf-1/battery-3d-demo.git
cd battery-3d-demo
npm install
npm run build
```

需要 Git 与 Node.js 22或以上。开发依赖安装需要网络，成品运行不需要网络。全新克隆目录验证可检查依赖和构建完整性；它不等同于已经在另一台实体电脑上实测。

浏览器验收使用独立的Playwright运行时和Chrome。可设置 `PLAYWRIGHT_MODULE_PATH`、`CHROME_EXECUTABLE_PATH` 后分别运行 `node tests/two-wheeler.mjs`、`node tests/power-tool.mjs`、`node tests/home-storage.mjs`、`node tests/gallery.mjs`。
