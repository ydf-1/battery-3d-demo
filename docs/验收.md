## 完成的整合与优化

- 保留根目录两轮车源码和上午提交的户用储能柜，加入已经完成的电动工具模型。
- 新增统一模型切换入口，支持鼠标、键盘切换与各模型操作指南。
- 三套统一深色展示界面、标注、字体、侧栏和控制栏。手机采用两列部件清单与全宽推荐详情。
- 增加代码生成的细微注塑、金属拉丝和白色粉末涂层质感；统一灯光及较轻的地面投影，保持电路板深绿、金属本色及原有塑料配色。
- 保留三套的几何数量、部件身份、批准文案和拆解方式。储能柜保留先开外部壳件、再展开内部的阶段动画。
- 修复两轮车和储能柜的跨选择归位：拆出某编号件，查看其他部件后，再点原编号仍可归位。
- 根目录一次 `npm run build` 更新三套独立成品与整合入口。

## 构建复验

使用新目录从远程克隆，安装依赖后构建：

```powershell
git clone https://github.com/ydf-1/battery-3d-demo.git
cd battery-3d-demo
npm install
npm run build
```

需要 Git 与 Node.js 22或以上。开发依赖安装需要网络，成品运行不需要网络。全新克隆目录验证可检查依赖和构建完整性；它不等同于已经在另一台实体电脑上实测。

浏览器验收使用独立的Playwright运行时和Chrome。可设置 `PLAYWRIGHT_MODULE_PATH`、`CHROME_EXECUTABLE_PATH` 后分别运行 `node tests/two-wheeler.mjs`、`node tests/power-tool.mjs`、`node tests/home-storage.mjs`、`node tests/gallery.mjs`。
