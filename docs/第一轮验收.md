## 修改文件及复验

- dist/model.js：精确材质角色与拆解计算入口；dist/assembly.js：实际顶点包围盒、等距分层和随动。
- dist/app.js：透明影棚、选择/恢复/灰显、镜头、分层时间轴、测量接口。
- dist/index.template.html、dist/round-one.css：两轮车浅色版面和深色按钮。build.mjs只给两轮车追加样式。
- gallery.mjs：只有切换到两轮车时采用52px浅色顶栏；另外两套入口继续使用原76px顶栏。
- tests/round-one.mjs、tests/round-one-gallery.mjs：可复跑的交互、几何与入口验证；docs/需求.md、README.md与本轮证据文件同步更新。
- 更新dist/index.html、release/两轮车电池包-离线.html和release/3D电池模型-成品.html。其他两套源码及离线文件20项哈希检查未变。

执行 npm run build；设置 PLAYWRIGHT_MODULE_PATH 与 CHROME_EXECUTABLE_PATH 后执行 node tests/round-one.mjs 和 node tests/round-one-gallery.mjs。浏览器测量使用Chrome无头WebGL、Windows窗口模拟，未进行另一台实体电脑或手机实测。
